# Contributing

Thank you for your interest in this project.

This repository is primarily intended as a **portfolio and reference implementation**
of a pipeline for parsing brokerage note PDFs and monitoring operations.

## Scope

Small improvements are welcome, such as:
- documentation refinements
- code organization
- robustness and readability improvements

Changes that require real brokerage notes, client data, or proprietary rules
should **not** be included.

## Data and security

- Do not include real brokerage notes (PDFs)
- Do not include client or account information
- Use only synthetic or placeholder data when necessary
